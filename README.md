# Invoice Chaser

أداة ويب بسيطة لمتابعة الفواتير المستحقة وتذكير العملاء عبر واتساب أو البريد. A small web tool for tracking unpaid invoices and sending payment reminders.

## المزايا / Features

- متابعة الفواتير وحالاتها (قيد الانتظار، متأخرة، مدفوعة)
- قائمة يومية بمن حان موعد تذكيره
- رسائل تذكير بالعربية والإنجليزية تتغير حسب مدة التأخير
- طلب دفع قابل للطباعة أو الحفظ PDF مع رمز QR
- ملخص شهري، تصدير CSV، ونسخة احتياطية JSON
- قابل للتثبيت على الموبايل (PWA)

## ملاحظات / Notes

- لا يوجد سيرفر: البيانات تُحفظ في متصفح المستخدم فقط (localStorage).
- لا يوجد إرسال تلقائي: التطبيق يجهّز الرسالة والمستخدم يضغط للإرسال.
- "طلب الدفع" ليس فاتورة ضريبية.

## التشغيل / Run

افتح `index.html` في المتصفح، أو ارفع المجلد على أي استضافة ثابتة. Open `index.html`, or deploy the folder to any static host.

عند تعديل أي ملف بعد النشر، غيّر رقم النسخة في `sw.js` (`ic-v4` إلى `ic-v5` وهكذا).
